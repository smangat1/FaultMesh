# Benchmarks

The reproducible benchmark harness is a Milestone 4 deliverable. This directory is deliberately not
populated with invented measurements. The Milestone 1 end-to-end fixture under
`examples/buggy_python_project` is an acceptance test, not evidence of comparative performance.

Future benchmark records will include buggy and corrected implementations, ground truth,
reproduction commands, held-out cases, budgets, raw model metadata, precision/recall counts,
reproduction rate, latency, memory, calls, tokens, and the four planned ablations. Results must be
generated by the checked-in harness and must identify the model, quantization, hardware, and commit.
